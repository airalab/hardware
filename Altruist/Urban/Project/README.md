# Altruist Urban — EasyEDA Pro Project Files

> EasyEDA Pro project files for the Altruist Urban — an outdoor air quality module
> (particulate matter PM, noise level, temperature and humidity).
> **Open source hardware project files**: import or edit them in EasyEDA Pro.

## Contents

| File | Description |
|---|---|
| `ProPrj_Altruist Urban.epro2` | Complete EasyEDA Pro project archive: schematics and PCB layouts of all Urban boards (main board, TH, noise, indicators) plus project metadata. |

## How to open

- **Desktop:** [EasyEDA Pro desktop client](https://easyeda.com/page/download/) (Windows / Linux / macOS) → *File → Import → EasyEDA Pro Project…* → select the `.epro2` file.
- **Online (no install):** [EasyEDA Pro online editor](https://pro.easyeda.com/editor/) → *File → Import → EasyEDA Pro Project*.
- **OSHWLab (view / fork online):** <https://oshwlab.com/pinoutlimited/project_lelawbpf>
