# ESP32-C6-WROOM-1-N8 — свободные GPIO разъёма расширения CN4 (HC-PM254-8.5H-2x7PS)

Устройство: Altruist urban. Порт расширения для DIY-модулей — 2x7 (14 контактов), шаг 2.54 мм.
Резерв: пины IO22 и IO20 отданы модулю LoRa Meshtastic — самодельные модули их не занимать.

Источники (назначение пинов взято из официальной документации Espressif):
- ESP32-C6-WROOM-1 / WROOM-1U Datasheet v1.4 — табл. 3-1 «Pin Definitions», гл. 4 «Boot Configurations», гл. 6 «Electrical Characteristics»
- ESP32-C6 Series Datasheet v1.5 — табл. 2-4/2-5 «IO MUX Pin Functions», табл. 2-7 «LP IO MUX Functions», табл. 2-8/2-9 «Analog Functions», разд. 2.3.5 «Peripheral Pin Assignment»

Нумерация пинов модуля: 29-контактный корпус WROOM-1 (GND=1 … EPAD=29).

## Итог по свободным пинам

Полноценных цифровых сигналов (приоритет P2, без ограничений): IO23, IO21, IO18, IO19 — 4 пина.
С оговорками: IO6 (JTAG MTCK; зато ADC и LP), IO15 (strapping/JTAG-выбор; требует внешней подтяжки), TXD0/RXD0 (UART0 — консоль/загрузчик текущей прошивки; лучше не занимать под критичные функции, кроме «только слушать»).

Самое универсальное свободное место — IO6 (CN4 пин 6): единственный пин порта, который может быть и аналоговым входом (ADC1_CH6), и GPIO, и работать в deep-sleep (LP_GPIO6 / LP_I2C_SDA).

## Электрические ограничения

1. Все IO — 3.3 В логика (VDD33 = 3.0–3.6 В, типично 3.3 В). Подавать 5 В или VDD+0.3 В на любой IO запрещено (Absolute Maximum Ratings, табл. 6-1).
2. Модули с 5-вольтовой логикой (например платы на ATmega или Arduino UNO) подключать через level shifter.
3. Ток нагрузки на цифровые пины — умеренный (типичный выходной ток GPIO ESP32-C6 ~20-40 мА на пин); для реле/светодиодов/модулей с большим потреблением — использовать транзистор/драйвер, питание брать с 3V3/5V.
4. Не подавать внешнее питание на пины 3V3 и 5V, если основная плата уже запитана: это шины платы, а не вход заряда.

## Использование периферии на свободных пинах

- I2C: любые два свободных пина (GPIO Matrix позволяет I2C почти везде). Удобная пара: IO18 (SDA) + IO23 (SCL). LP-вариант (работает в deep-sleep): LP_I2C_SDA = IO6, LP_I2C_SCL = IO7, но IO7 на CN4 не выведен, поэтому полноценный LP-I2C из разъёма не собрать.
- SPI (SPI2/FSPI): FSPICLK = IO6, FSPICS2/3/4/5 = IO18/IO19/IO20/IO21 (FSPICS0/1 = GPIO16/GPIO17 = TXD0/RXD0). Важно: FSPID (MOSI) = IO7, FSPIQ (MISO) = IO2, FSPIHD = IO4, FSPIWP = IO5 — эти пины на CN4 НЕ выведены, поэтому полноценную FSPI-шину (с MISO/MOSI) из одного разъёма CN4 не собрать. Если DIY-модулю нужен SPI, используйте программную (bit-bang) реализацию через GPIO Matrix на произвольных свободных пинах.
- UART: UART1/UART2 можно назначить на любые свободные пины через GPIO Matrix. Не занимать TXD0/RXD0 (GPIO16/GPIO17) — это UART0 (консоль/загрузчик).
- PWM/LED/RMT и т.п.: любой GPIO из свободных через GPIO Matrix.
- ADC: только IO6 (ADC1_CH6) — единственный аналоговый вход на разъёме.
