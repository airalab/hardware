# Altruist Insight — EasyEDA Pro Project Files

> EasyEDA Pro project files for the Altruist Insight — an ESP32-C6 based indoor air quality
> monitor (CO₂, temperature, humidity, pressure, 4.2" e-paper display, microSD logging).
> **Open source hardware project files**: import or edit them in EasyEDA Pro.

## Contents

| File                            | Description                                                                                                                            |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `ProPrj_Altruist insight.epro2` | Complete EasyEDA Pro project archive: schematic, PCB layout and project metadata for the current stable release, **Altruist Insight**. |

## How to open

- **Desktop:** [EasyEDA Pro desktop client](https://easyeda.com/page/download/) (Windows / Linux / macOS) → *File → Import → EasyEDA Pro Project…* → select the `.epro2` file.
- **Online (no install):** [EasyEDA Pro online editor](https://pro.easyeda.com/editor/) → *File → Import → EasyEDA Pro Project*.
- **OSHWLab (view / fork online):** <https://oshwlab.com/pinoutlimited/project_pzemirdy>
